## ✨ Key Features

1. **Zero-Config Docker Deployment (`docker-compose.yml`):** Runs out-of-the-box on Hostinger VPS Docker Manager or any Linux/Windows/macOS server using official `php:8.2-cli-alpine`.
2. **Real-Time Academic & Semantic Integration:** Connects over HTTPS to `https://million.elnemer-ai.com` to stream **Schema.org JSON-LD**, **W3C RDF/Turtle**, **OAI-PMH 2.0**, and **200-Page PDF Volumes** (`1` to `7,000,000`).
3. **Cryptographic Verification:** Verifies **SHA-256 Merkle Proofs** anchored in **Harvard Dataverse** (`doi:10.7910/DVN/TTKZSO`, `doi:10.7910/DVN/FZISTQ`, `doi:10.7910/DVN/UFYQDK`) and **CERN Zenodo** (`10.5281/zenodo.24051667`).
4. **Included Python CLI Verifier (`cli_verifier.py`):** Query any volume from `1` to `7,000,000` directly from the terminal.

## 🐳 Quick Start (Local / Self-Hosted Docker)

```bash
git clone https://github.com/ElNeMeR70/elnemer-pharaohs-museum-node.git
cd elnemer-pharaohs-museum-node
docker compose up -d
```

Then open `http://localhost:8082` in your browser!
